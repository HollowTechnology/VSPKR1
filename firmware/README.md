<center><h1>VSPKR1 Firmware</h1></center>

### Notes about this firmware:

- This firmware is made in Python, so you need to use MicroPython on the VSPKR1 PCB, or whatever ESP32-S3 kit you use.
- This firmware is open source, so modify it as you want!
- If you would like to modify this code, you will probabaly want to download the lastest community bundle, and copy the lib folder from the zip to the root of this repo. You can download the bundle from [here](https://circuitpython.org/libraries)
- Also, if you are modifying this code, install the MicroPython V2 extension.
